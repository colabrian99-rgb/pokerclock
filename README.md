# 포커 블라인드 클락

포커 게임용 블라인드 타이머 웹앱입니다. 설치 없이 브라우저에서 바로 사용할 수 있습니다.

## 주요 기능
- 큰 카운트다운, 시작/일시정지, 이전/다음 레벨
- -1분, -10초, +10초, +1분 시간 조정, 시간 숫자를 눌러 직접 입력
- 설정 화면에서 레벨별 블라인드(SB/BB), 앤티, 시간, 브레이크 편집
- 기본값: 12레벨 (25/50 ~ 1000/2000)

## 파일 구성
- `index.html`: 앱 전체 (단일 파일)
- `manifest.json`: 홈 화면 설치용 설정
- `icon.svg`: 앱 아이콘
- `README.md`: 이 설명서

## GitHub Pages로 배포하기
1. GitHub에 로그인하고 **New repository**를 누릅니다.
2. Repository name을 정하고(예: `poker-blind-clock`), **Public**을 선택한 뒤 생성합니다.
   - 무료 계정은 Public 저장소만 Pages를 쓸 수 있습니다.
3. **uploading an existing file**을 누르고 위 파일들을 모두 끌어다 놓습니다.
4. **Commit changes**를 누릅니다.
5. 저장소의 **Settings → Pages**로 들어갑니다.
6. Source를 **Deploy from a branch**, Branch를 **main / (root)**로 선택하고 Save를 누릅니다.
7. 1~2분 뒤 주소가 나옵니다: `https://<아이디>.github.io/<저장소 이름>/`

## 사용자에게 전달하기
- 위 주소를 카카오톡으로 보내면 됩니다.
- 휴대폰에서 링크를 연 뒤 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱 아이콘처럼 쓸 수 있습니다.
- 카카오톡 내부 브라우저에서 열리면 **다른 브라우저로 열기**를 눌러 주세요.
